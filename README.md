# machicoro_simulation

街コロ（Machi Koro）ボードゲームのシミュレーター

## 概要

**街コロ**はサイコロを振ってカードの効果でコインを集め、ランドマークを建設していくボードゲームです。  
このシミュレーターでは複数の AI 戦略エージェントを対戦させ、勝率・平均ターン数などの統計を収集できます。

## ゲームルール

### 基本の流れ
1. **サイコロを振る** ― 駅（ランドマーク）を建設すると 2 つ振れる
2. **カード効果を発動** ― 出た目に対応するカードの効果が発生
3. **建設フェーズ** ― コインを使ってカードやランドマークを 1 枚購入
4. **勝利条件** ― 4 つのランドマークをすべて建設したプレイヤーが勝利

### カードの種類

| 色 | 種類 | 発動タイミング | 代表例 |
|---|---|---|---|
| 🔵 青 | 第一産業 | 誰のターンでも | 麦畑・牧場・鉱山 |
| 🟢 緑 | 第二産業 | 自分のターンのみ | パン屋・コンビニ・チーズ工場 |
| 🔴 赤 | 飲食店 | 他人のターン | カフェ・ファミリーレストラン |
| 🟣 紫 | 大型施設 | 自分のターン（1 枚制限） | スタジアム・テレビ局 |

### ランドマーク

| ランドマーク | コスト | 効果 |
|---|---|---|
| 駅 | 4 | 2 つのサイコロを振れる |
| ショッピングモール | 10 | パン屋・コンビニ・カフェ等の収入 +1 |
| 遊園地 | 16 | ゾロ目ならもう一度振れる |
| ラジオ塔 | 22 | 1 ターンに 1 回振り直せる |

## インストール

```bash
pip install -r requirements.txt
```

## 実行方法

```bash
# デフォルト（1000 ゲーム、2 プレイヤー、landmark vs income 戦略）
python simulate.py

# オプション指定例
python simulate.py -n 500 -p 3 -s random landmark income --seed 42 -v
```

### オプション

| オプション | 説明 | デフォルト |
|---|---|---|
| `-n` / `--num-games` | シミュレーション回数 | 1000 |
| `-p` / `--players` | プレイヤー数 | 2 |
| `-s` / `--strategies` | 使用する戦略 | `landmark income` |
| `--seed` | 乱数シード | なし |
| `-v` / `--verbose` | 最初のゲームの詳細ログを表示 | False |

### 戦略一覧

| 名前 | 説明 |
|---|---|
| `random` | すべてランダムに決定 |
| `landmark` | 安価なランドマークを優先建設し、次に高価なカードを購入 |
| `income` | 収入最大化カードを優先購入し、まず駅を建設 |
